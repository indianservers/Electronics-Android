# Changelog

## 1.0 — Phases 1–6

- Component platform: catalog, pins, units, favorites, and JSON persistence.
- Guided lessons with circuit criteria.
- Circuit intelligence and one-tap fixes that can be undone.
- Live transient slices, oscilloscope, meter, and AC sweep.
- Arduino-subset and MicroPython-subset firmware on placed boards, with UART/I²C/SPI event buses.
- Datasheet-backed board definitions for 11 development boards.
- Phase 6: release audit, Preview labels on two unfinished project cards, settings text that states educational limits, corrupt-save wording, and a 5 V / 1 kΩ / 100 µF RC golden test.
